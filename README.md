Entry for the [One-Line Laugh-Off](https://make.fun/competitions/u-zkhiel-one-line-laugh-off-714618ae)
competition on [make.fun](https://make.fun): a program that writes exactly one
funny line to `/output/entry.txt`.

## Run

```sh
node main.ts
cat /output/entry.txt
```

Node 22, stdlib only — no dependencies, no network.

## The line

> I finally read the terms and conditions — that's why this is my obituary.
